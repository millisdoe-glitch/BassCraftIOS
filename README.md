# BassCraft: Subwoofer Lab (iOS Port)

Нативный iOS-порт и симулятор автозвука **BassCraft: Subwoofer Lab**, написанный на **SwiftUI** с использованием **AVAudioEngine** для реального синтеза низких частот (20–90 Гц).

---

## 🛠 Возможности

1. **Лаборатория SPL (SPL Sensor):**
   - Расчёт реального звукового давления в дБ с учётом салонного подъёма (Cabin Gain).
   - Интерактивный вибро-визуализатор диффузора (ход пропорционален мощности и частоте).
   - Индикаторы перегрузок: **CLIP** (клиппинг усилителя), **XMAX** (превышение линейного хода / стук катушки), **TEMP** (термический нагрев катушки).
   - Генератор реального звукового синуса (AVAudioEngine) для прослушивания через динамики или наушники.

2. **Расчёт короба (Box Designer):**
   - Закрытый ящик (ЗЯ) и Фазоинвертор (ФИ).
   - Живой расчёт частоты настройки порта $F_b$ по площади и длине.
   - Моделирование разгрузки диффузора на частоте настройки и акустического КЗ ниже настройки.

3. **Коммутация катушек и усилитель (Wiring & Amp):**
   - Моноблоки от 800W до 4000W.
   - Параллельное и последовательное подключение (D1, D2, D4).
   - Настраиваемый сабсоник-фильтр (HPF) для защиты диффузора.

4. **База сабвуферов (Presets):**
   - Pride Bb.3, Deaf Bonce DB-SA272, Sundown Audio SA-12, Kicker CompC, Pride T15 v.3 и др.

## 🚀 Как получить готовый `.ipa` через GitHub Actions

Сборка происходит автоматически в облаке на виртуальном Mac (бесплатно):

1. **Создайте новый репозиторий на [GitHub.com](https://github.com/new)** (например, с именем `BassCraftIOS`).
2. **Отправьте этот проект в GitHub** (выполните в папке проекта):
   ```bash
   git init
   git add .
   git commit -m "Init BassCraft iOS"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/BassCraftIOS.git
   git push -u origin main
   ```
3. **Скачайте `.ipa`:**
   - Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
   - Откроется процесс **Build BassCraft iOS IPA**.
   - Примерно через 2 минуты сборка завершится.
   - Внизу страницы в секции **Artifacts** нажмите на **BassCraft-iOS-IPA** и скачайте готовый архив с `.ipa` файлом!

## 📲 Как установить `.ipa` на iPhone

Так как iOS требует подписи приложений, используйте любой популярный инструмент сайдлоадинга:

* **Способ 1: [Sideloadly](https://sideloadly.io/) (Windows/Mac) — Рекомендуется**
  1. Подключите iPhone к компьютеру через кабель.
  2. Перетащите скачанный `BassCraft.ipa` в окно Sideloadly.
  3. Введите свой Apple ID (для бесплатной автоматической подписи).
  4. Нажмите **Start**. Приложение появится на рабочем столе iPhone!
  5. На iPhone перейдите в *Настройки → Основные → VPN и управление устройством* и нажмите «Доверять».

* **Способ 2: [AltStore](https://altstore.io/)**
  - Установите через AltServer прямо по воздуху (Wi-Fi).

* **Способ 3: TrollStore**
  - Если на вашем iPhone поддерживается TrollStore, установка происходит прямо в одно нажатие без необходимости ПК.
